# Wikipedia

A small Python utility for querying the Wikipedia API and extracting article summaries.

About

This project provides simple scripts to search Wikipedia, fetch article summaries, and save results for further processing. It's useful for demos, learning API usage, and quick research tasks.

Features

- Search Wikipedia by query
- Get article summaries
- Export results as JSON or plain text

Installation

1. Create a virtual environment and activate it:

python -m venv .venv
source .venv/bin/activate  # macOS / Linux
.\.venv\Scripts\activate   # Windows (PowerShell)

2. Install dependencies (if a requirements.txt exists):

pip install -r requirements.txt

Quick start

# Example usage (adjust based on actual scripts in the repo)
python wiki_search.py "Artificial intelligence"
